# 프로젝트 저장 이력

Ctrl+S 또는 저장 버튼으로 프로젝트 JSON을 변경해 저장할 때 덮어쓰기 전 파일을 같은 폴더의
`.project_history/<프로젝트 JSON 파일명>/` 아래에 보존한다. 파일명은 UTC 시각과
고유 식별자를 포함한다. 변경 없는 동일 바이트 저장은 이력을 추가하지 않는다.
페이지 전환 등 자동 저장과 기존 `.backup` 갱신은 이력을 추가하지 않는다.
이력 파일은 자동 삭제하지 않는다.

글자 크기 재평가는 시작 전에 최신 텍스트 상태를 프로젝트에 저장하고
그 상태를 이력에 한 번 보존한다. 시작 전 저장이나 이력 보존이 실패하면
재평가를 실행하지 않는다. 수동 저장도 이전 파일의 이력 보존에 실패하면
프로젝트를 덮어쓰지 않는다. 새 JSON은 고유 임시 파일을 완성한 뒤 교체한다.

복구할 때는 앱에서 프로젝트를 닫고 현재 JSON을 별도로 보존한 다음, 원하는
이력 파일을 원래 프로젝트 JSON 이름으로 복사한다. 다시 프로젝트를 열어 확인한다.
일부 페이지만 복구할 때는 해당 `pages` 항목만 옮겨 나머지 최신 편집을 유지한다.

이력은 저장 경계의 JSON이며 이미지·마스크·모델·외부 래스터 자산의 사본은 아니다.
저장되지 않은 임의 시점의 편집이나 기능 도입 이전의 상태를 복원하지는 못한다.
검증은 `tests/test_project_save_history.py`와 재평가·Canvas 저장 회귀를 사용한다.
