# Format Inspector Selection Design

이 문서는 우측 글꼴 형식 패널, 글로벌 글꼴 형식, 사용자 프리셋, 텍스트 블록
다중 선택, Rich Text 부분 선택의 표시와 적용 정책을 정의한다. 핵심 원칙은
사용자에게 현 상태에서 할 수 있는 일과 할 수 없는 일을 표시값과 버튼 활성 상태로
명확하게 알려 주는 것이다.

## 설계 원칙

패널은 현재 선택된 대상의 정확한 상태를 반영해야 한다. 텍스트 블록, 여러 텍스트
블록, Rich Text 선택 구간, Rich Text cursor 위치, 프리셋, 글로벌 글꼴 형식 중
무엇이 현재 대상인지 먼저 정하고, 그 대상에서 실제로 확인한 서식만 표시한다.

패널은 실제 선택 대상에서 확인한 값만 보여 준다. 여러 대상의 값이 섞였는데
글로벌 글꼴 형식을 fallback으로 보여 주면 안 된다. 현재 구현처럼 여러 텍스트
블록을 선택했을 때 글로벌 글꼴 형식 값을 표시하고 크기에만 `+`를 붙이는 방식은
선택 대상의 실제 상태를 숨기므로 제거한다.

사용자가 어떤 버튼을 누를 수 있는지는 현재 선택 상태에서 의미 있는 동작이 존재할
때만 열어 둔다. 동작 대상이 없거나, 여러 후보가 섞여 있어 하나의 결과를 정할 수
없으면 버튼을 비활성화한다.

프리셋은 전체 `FontFormat` 단위로 저장한다. 따라서 프리셋으로 가져오기 동작은
프리셋이 저장할 수 있는 모든 서식 필드가 선택 대상 전체에서 동일할 때만 가능하다.
하나라도 다르면 가져올 수 없다. 사용자는 버튼 비활성 상태를 보고 하나만 선택하거나
먼저 서식을 통일해 처리한다.

## 선택 대상 우선순위

패널의 표시 대상은 다음 우선순위를 따른다.

- Rich Text 편집 중 선택 구간 또는 cursor 대상
- 선택된 텍스트 블록
- 선택된 사용자 프리셋
- 글로벌 글꼴 형식

텍스트 블록이 선택된 상태에서는 프리셋이 선택되어 있어도 텍스트 블록이 우선한다.
텍스트 블록 선택을 해제하면 선택된 프리셋이 있으면 프리셋으로 돌아가고, 프리셋도
선택되어 있지 않으면 글로벌 글꼴 형식으로 돌아간다.

## 글로벌 글꼴 형식

글로벌 글꼴 형식은 아무 텍스트 블록도 선택하지 않았고 프리셋도 선택하지 않았을 때
보이는 기본 서식이다. 새 텍스트 블록 생성과 자동 조판 기본값의 기준이 된다.

다만 프리셋이 선택되어 있는 동안에는 선택된 프리셋을 실효 글로벌 글꼴 형식으로
본다. 이 상태에서 새 텍스트 블록을 만들거나 전체 인식/번역으로 새 텍스트 블록
서식이 생성되면, 기본 글로벌 글꼴 형식이 아니라 선택된 프리셋의 `FontFormat`을
기준으로 삼는다. 프리셋 선택을 해제해야 기본 글로벌 글꼴 형식이 다시 기본값이 된다.

현재 구현에서 `Global Font Format` 제목이 표시되는 상태는 대부분 실제 글로벌 글꼴
형식이 편집 대상인 경우이다. 확인된 예외는 여러 텍스트 블록을 선택한 경우이다.
이때도 `set_textblk_item(None, multi_select=True)` 경로가 글로벌 글꼴 형식을
표시하고 제목도 그대로 `Global Font Format`으로 남기므로, 사용자는 여러 블록의
공통 서식을 보고 있다고 오해할 수 있다.

따라서 글로벌 글꼴 형식 표시는 다음처럼 확정한다.

- 실제 글로벌 글꼴 형식이 편집 대상일 때만 우측 패널 상단 타이틀바에
  `Global Font Format`을 표시한다.
- 글로벌 글꼴 형식이 현재 선택 대상일 때 타이틀바 글자를 파란색으로 표시한다.
- 여러 텍스트 블록이 선택된 경우에는 `Global Font Format`을 표시하지 않고
  `Text Blocks #1, #2, ...`처럼 선택된 블록 번호를 나열한 제목을 표시한다.
  제목 폭을 넘으면 말줄임 처리한다.
- 단일 텍스트 블록이 선택된 경우에는 기존처럼 `TextBlock #<idx>`를 표시한다.
- 프리셋이 선택된 경우에는 프리셋 이름이 포함된 제목을 표시한다.

장기 검토 후보는 다음과 같다.

- 장기적으로 삭제 불가능한 기본 프리셋 하나를 도입해 글로벌 글꼴 형식을 프리셋
  목록 안에 포함하는 방안을 검토한다. 다만 프리셋을 사용하지 않는 사용자에게
  항상 자리 하나를 차지한다는 단점이 있으므로 별도 판단이 필요하다.

## 사용자 프리셋

사용자 프리셋 label 클릭은 프리셋을 패널의 편집 대상으로 선택하는 동작이다. 클릭
자체가 글로벌 글꼴 형식을 자동으로 덮어쓰면 안 된다. 파란 테두리는 "현재 이
프리셋을 편집 중"이라는 뜻으로 고정한다.

프리셋이 선택된 상태에서 패널 값을 바꾸면 해당 프리셋 자체가 수정된다. 이 상태에서
텍스트 블록을 선택하면 텍스트 블록 서식이 우선 표시되고, 텍스트 블록 선택을 풀면
다시 선택된 프리셋이 표시된다. 프리셋 선택을 해제하면 글로벌 글꼴 형식으로 돌아간다.

기존 구현에서는 프리셋 label 클릭이 "선택"과 "글로벌 글꼴 형식에 복사"를 동시에
수행했다. 새 정책에서는 두 의미를 분리한다.

- label 클릭: 프리셋을 선택/편집 대상으로 삼는다.
- 왼쪽 화살표: 프리셋을 현재 적용 대상에 적용한다.
- 오른쪽 화살표: 현재 가져오기 대상의 서식을 프리셋으로 가져온다.

## 프리셋 화살표 버튼

왼쪽 화살표는 `preset -> 대상`이다. 오른쪽 화살표는 `대상 -> preset`이다.

### 왼쪽 화살표

왼쪽 화살표는 프리셋 값을 현재 적용 대상에 적용한다.

사용 가능 조건은 다음과 같다.

- 텍스트 블록이 선택된 경우, 프리셋을 선택 텍스트 블록에 적용한다.
- Rich Text 편집 중 적용 가능한 선택 구간 또는 cursor 대상이 있는 경우, 프리셋을
  해당 범위 또는 cursor 서식에 적용한다.
- 텍스트 블록도 프리셋도 선택되지 않은 경우, 프리셋을 글로벌 글꼴 형식에 적용한다.

사용 불가 조건은 다음과 같다.

- 프리셋만 선택된 경우. 이 상태에서는 프리셋을 자기 자신에게 적용하는 셈이므로
  의미가 없다.

### 오른쪽 화살표

오른쪽 화살표는 현재 가져오기 대상의 서식을 프리셋으로 가져온다.

사용 가능 조건은 다음과 같다.

- 텍스트 블록도 프리셋도 선택되지 않은 경우, 글로벌 글꼴 형식을 프리셋으로 가져온다.
- 텍스트 블록이 하나 선택된 경우, 그 텍스트 블록의 서식을 프리셋으로 가져온다.
- 여러 텍스트 블록이 선택됐고 프리셋이 저장하는 모든 서식 필드가 통일되어 있으면,
  공통 서식을 프리셋으로 가져온다.
- Rich Text 편집 중 선택 구간이 있고 프리셋이 저장하는 모든 서식 필드가 통일되어
  있으면, 선택 구간의 공통 서식을 프리셋으로 가져온다.

사용 불가 조건은 다음과 같다.

- 텍스트 블록 선택은 없고 프리셋만 선택된 경우. 이 상태에서는 프리셋에서 프리셋으로
  가져오는 셈이므로 의미가 없다.
- 여러 텍스트 블록이 선택됐는데 프리셋이 저장하는 서식이 통일되어 있지 않은 경우.
- Rich Text 편집 중 선택 구간의 서식이 통일되어 있지 않은 경우.

## 다중 텍스트 블록 표시

여러 텍스트 블록을 선택하면 패널은 선택된 블록들의 aggregate 서식을 표시한다.
글로벌 글꼴 형식 값은 표시하지 않는다.

각 필드의 표시 정책은 다음과 같다.

- 모든 선택 블록의 값이 같으면 그 값을 표시한다.
- 값이 하나라도 다르면 해당 필드는 비우거나 mixed 상태로 표시한다.
- 텍스트 입력형 control은 비운다.
- combobox는 빈 값 또는 mixed placeholder를 표시한다.
- color swatch는 mixed swatch를 표시한다.
- bold, italic, underline, vertical, alignment 같은 아이콘 control은 제3의
  indeterminate 상태로 표시한다.

다중 선택 상태에서 사용자가 값을 직접 지정하면 선택된 모든 텍스트 블록에 그 값을
적용한다. mixed 상태는 입력을 막는 상태가 아니라, 현재 값이 통일되어 있지 않음을
알리는 상태이다.

폰트 크기 키우기/줄이기는 예외적으로 기존처럼 각 텍스트 블록의 원래 크기에 비례해
동작한다. 크기가 mixed인 경우 size 입력칸은 비워 두지만, 키우기/줄이기 버튼은
상대 배율을 각 블록에 적용한다. 직접 크기를 입력하면 선택 대상 전체의 크기를 그
절대값으로 통일한다.

## Rich Text 표시

Rich Text 편집 중 선택 구간이 있으면 패널은 선택 구간 안의 fragment 서식을
aggregate한다.

- 선택 구간의 모든 fragment 값이 같으면 그 값을 표시한다.
- 선택 구간 안에 값이 섞여 있으면 해당 필드는 mixed 상태로 표시한다.
- 프리셋이 저장하는 필드 중 하나라도 mixed이면 오른쪽 화살표는 비활성화한다.
- mixed 상태에서 사용자가 값을 직접 지정하면 선택 구간 전체에 그 값을 적용한다.

선택 구간이 없고 cursor만 있는 경우에는 cursor 위치의 char format을 표시한다.
패널 조작은 이후 입력될 텍스트 또는 현재 cursor char format에 적용한다. cursor
위치는 단일한 현재 서식으로 간주하므로 오른쪽 화살표로 해당 서식을 프리셋에
가져올 수 있다.

cursor가 fragment 경계, 빈 문단, 빈 문서처럼 모호한 위치에 있을 때는 Qt의
`QTextCursor.charFormat()`을 우선 기준으로 삼고, 필요한 경우 block format 또는
document default format으로 fallback한다. 이 fallback은 Rich Edit 내부의 현재
입력 서식을 찾기 위한 것이며, 글로벌 글꼴 형식을 표시하기 위한 fallback이 아니다.

부분 Rich Text 변경 시 `TextBlock.fontformat`을 무조건 덮어쓰지 않는다. 대표값은
문서 전체가 같은 값으로 통일되었거나 명시적으로 block 전체 서식을 바꿀 때만 갱신한다.

## 가져오기 가능성 판정

오른쪽 화살표의 활성화 여부는 프리셋 저장 필드 전체를 기준으로 판정한다. 판정 대상
필드는 `FontFormat`이 저장하고 프리셋으로 복사하는 필드이다.

판정 예시는 다음과 같다.

- font family가 다르면 가져올 수 없다.
- font size가 다르면 가져올 수 없다.
- font weight가 다르면 가져올 수 없다.
- foreground color가 다르면 가져올 수 없다.
- stroke, shadow, gradient, alignment, vertical, spacing 값이 다르면 가져올 수 없다.

프리셋이 저장하지 않는 내부 상태나 별도 런타임 상태는 고려하지 않는다.

## 선택 표시 안정화

Qt minor 버전에 따라 stylesheet 기반 선택 표시가 늦게 갱신되거나 잔상처럼 남을 수
있다. 선택 표시 변경은 내부 상태와 화면 표시가 어긋나지 않게 처리해야 한다.

최소 정책은 다음과 같다.

- 내부 active/checked 상태를 먼저 갱신한다.
- stylesheet 또는 dynamic property를 갱신한다.
- 필요한 경우 `style().unpolish()`, `style().polish()`, `update()`로 표시 갱신을
  강제한다.

장기적으로는 문자열 stylesheet 토글보다 dynamic property 기반 스타일링을 검토한다.
예를 들어 `active=true`, `checked=true`, `mixed=true`를 widget property로 두면
상태와 표시의 대응을 더 명시적으로 만들 수 있다.

## 구현 단계 제안

1. 프리셋 label 클릭과 global 복사 동작을 분리한다.
2. 프리셋 화살표 버튼의 활성/비활성 조건을 위 정책에 맞춘다.
3. 여러 텍스트 블록 선택 시 global fallback 표시를 제거하고 aggregate 표시를
   도입한다.
4. 프리셋 저장 필드 전체에 대한 "통일됨/mixed" 판정 helper를 만든다.
5. Rich Text 선택 구간 aggregate helper를 추가한다.
6. 아이콘 control과 color swatch의 mixed 상태 표시를 통일한다.
